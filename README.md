## 🛠️ Development & Deployment

### Run Locally:
```bash
# 1. Install dependencies (already installed)
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```

### Deploying:
The project is built with standard Vite + React and can be deployed with one click to **Vercel**, **Netlify**, or **GitHub Pages**.
